ระบบบริหารจัดการยืม-คืนอุปกรณ์คอมพิวเตอร์ (COM-EQUIP) ออกแบบมาเพื่ออำนวยความสะดวกในการยืมและคืนอุปกรณ์คอมพิวเตอร์และอุปกรณ์ต่อพ่วง ให้มีความสะดวก รวดเร็ว ตรวจสอบสถานะได้แบบเรียลไทม์ พร้อมอินเทอร์เฟซที่สวยงาม ทันสมัย และรองรับการใช้งานบนทุกอุปกรณ์ (Responsive Design)

---

## ✨ ฟีเจอร์หลักของระบบ (Features)

### 1. 🏠 หน้าแรก (Home Dashboard)
- แบนเนอร์ต้อนรับและปุ่มทางลัดเข้าสู่ระบบยืมอุปกรณ์
- การ์ดสรุปสถิติอุปกรณ์ทั้งหมด, อุปกรณ์ที่ถูกยืม และพร้อมใช้งาน
- หมวดหมู่อุปกรณ์ (เมาส์, คีย์บอร์ด, หน้าจอ, หูฟัง, สายเชื่อมต่อ, อุปกรณ์อื่นๆ)
- รายการอุปกรณ์แนะนำพร้อมปุ่ม **ดูรายละเอียด (Modal)**

### 2. 💻 รายการอุปกรณ์ (Equipment Catalog)
- แสดงรายการอุปกรณ์คอมพิวเตอร์ทั้งหมดในระบบ
- สามารถกรองอุปกรณ์ตามประเภทหมวดหมู่ได้
- แสดงสถานะความพร้อมใช้งาน (พร้อมใช้งาน / ถูกยืมแล้ว)
- สามารถคลิกเพื่อดูรายละเอียดอุปกรณ์ทั้งหมดได้อย่างครบถ้วน

### 3. 📤 ระบบยืมอุปกรณ์ (Borrow Management)
- ฟอร์มกรอกข้อมูลผู้ยืม (รหัสผู้ยืม, ชื่อ-นามสกุล, สาขาวิชา/แผนก, เบอร์โทรศัพท์, วัตถุประสงค์, วันที่ยืม และกำหนดวันคืน)
- ตารางเลือกอุปกรณ์พร้อมปุ่มปรับเพิ่ม/ลดจำนวนอุปกรณ์ (+ / -)
- ระบบตรวจสอบความถูกต้องของข้อมูล (Form Validation)
- หน้าต่างป๊อปอัปแจ้งเตือนเมื่อบันทึกข้อมูลยืมสำเร็จ พร้อมอัปเดตข้อมูลเข้าสู่ตารางสถานะโดยอัตโนมัติ

### 4. 📥 ระบบคืนอุปกรณ์ (Return Management)
- ค้นหารายการยืม หรือคลิกปุ่ม **"คืน"** จากตารางเลือกรายการเพื่อดึงข้อมูลอัตโนมัติ
- รองรับการป้อนข้อมูลและแก้ไขข้อมูลการคืนได้อย่างอิสระทุกช่อง
- เลือกสภาพอุปกรณ์เมื่อนำมาคืน (ปกติ / ชำรุด) พร้อมบันทึกหมายเหตุ
- แจ้งเตือนการคืนอุปกรณ์สำเร็จและอัปเดตสถานะ

### 5. 📊 ตรวจสอบสถานะ (Status Tracking)
- ตารางแสดงประวัติและสถานะการยืม-คืนอุปกรณ์แบบเรียลไทม์
- แสดงป้ายสถานะชัดเจน (**พร้อมใช้งาน** / **ถูกยืม** / **ส่งคืนแล้ว**)
- ฟังก์ชันค้นหาและกรองข้อมูลสถานะตามชื่ออุปกรณ์ หรือประเภท

### 6. 🔐 ระบบผู้ดูแลระบบ (Admin Authentication)
- เมนู Dropdown สำหรับ **ผู้ดูแลระบบ (Admin)** บริเวณ Navbar
- สามารถดูข้อมูลส่วนตัว, ตั้งค่าระบบ และดูรายงานสรุปประจำเดือนได้
- ระบบเข้าสู่ระบบ (Sign In) และ ออกจากระบบ (Logout) แบบไดนามิก
